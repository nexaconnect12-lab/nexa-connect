# Cash-close retained-event replay

Operational CLI for POS-owned `pos.cash-close.snapshot.v1` outbox events. Preview is read-only; execution requires exact scope, capture range, limit, operator UUID, `rebuild`/`retry` reason and the preview manifest. POS migration 7 supplies append-only run/attempt attribution; financial state, checkpoints and original events are not changed. Run `dotnet run --project src/Tools/NexaConnect.CashCloseReplay -- --help` from the repository root.

Inject `NEXACONNECT_CASH_CLOSE_REPLAY_DB` and, for execution, `NEXACONNECT_CASH_CLOSE_REPLAY_BROKER`; optional exchange is `NEXACONNECT_CASH_CLOSE_REPLAY_EXCHANGE`. Do not place credentials in arguments. JSON logging uses `nexaconnect-cash-close-replay`; optional `OTEL_EXPORTER_OTLP_ENDPOINT` enables log export. The operator UUID is asserted attribution; database `session_user` supplies credential attribution. Broker confirms do not prove projection. See [exact commands, least privilege, partial outcomes and verification](../../../docs/Deployment/Cash-Close-Recovery.md).
